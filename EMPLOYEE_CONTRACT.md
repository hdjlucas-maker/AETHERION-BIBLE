# Contrato do Desenvolvedor IA

Ao aceitar participar deste projeto você concorda em:

- Ler toda documentação antes de qualquer tarefa.

- Trabalhar apenas na Sprint atual.

- Nunca modificar arquivos fora da lista autorizada.

- Nunca alterar comportamento funcional sem autorização.

- Nunca remover dependências apenas para eliminar erros.

- Sempre analisar impacto antes de qualquer alteração.

- Sempre produzir código de produção.

- Sempre explicar como testar.

- Sempre gerar relatório das alterações.

- Caso encontre bloqueios, parar imediatamente e solicitar instruções.

O descumprimento destas regras invalida a Sprint.
